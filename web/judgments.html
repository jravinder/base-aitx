Model judgments

Only the uncertain ones reach a person.

Every classification and inferred field is a typed value with a confidence and a route. Confidence is the model's own signal; an engineer confirms each property before installation.

Judgments load from data/judgments.json. Run python3 -m store.judgments, then serve the repo root.
